Um percurso estruturado para o ensino superior

Este curso foi concebido para candidatos que pretendem ingressar no ensino superior através do regime Maiores de 23, com acompanhamento académico orientado e preparação focada na prova de acesso.

💻 Modalidade

Curso 100% online (aulas em direto)

📅 Início do curso

Primeira semana de fevereiro de 2027

⏱ Horário

Pós-laboral (compatível com atividade profissional)

🎯 Objetivo

Preparação completa para a prova de acesso ao ensino superior

👥 Vagas

Limitação de alunos para garantir acompanhamento individualizado

📚 Estrutura pedagógica

Conteúdos organizados de forma progressiva e orientada para resultados.

Porquê este curso?

O regime Maiores de 23 exige não apenas conhecimento, mas preparação estratégica para avaliação. Este programa foi estruturado para colmatar lacunas de formação e desenvolver competências essenciais para o sucesso na prova.

  • Metodologia orientada para exame
  • Apoio na organização do estudo
  • Simulações de avaliação
  • Preparação progressiva e estruturada

Pré-inscrições abertas

As vagas são limitadas e preenchidas por ordem de candidatura.
